# **JKEYYY CINEMA**



### **Présentation**



JKEYYY CINEMA est un site web de cinéma réalisé dans le cadre d'un mini projet JavaScript Web Development. Il permet de découvrir des films, de rechercher un titre et de consulter ses informations détaillées.



#### **Fonctionnalités**



\- **Accueil** : découverte de plusieurs sélections de films, dont une sélection spéciale Halloween.

\- **Films de 2024** : possibilité de charger davantage de films.

\- **Recherche** : affichage des résultats en fonction du texte saisi, sans recharger la page.

\- **Détails d'un film** : affichage de l'affiche, du synopsis, du genre, des acteurs, du réalisateur, de la note IMDb et de la date de sortie DVD lorsque ces informations sont disponibles.



#### **Technologies utilisées**



\- HTML5

\- CSS3

\- JavaScript

\- API OMDb (Open Movie Database)



#### **Installation et utilisation**



1\. Cloner le dépôt GitHub.

2\. Ouvrir le fichier index.html dans un navigateur.

3\. Utiliser la navigation pour accéder à l'accueil, à la recherche et aux détails des films.



Le site utilise l'API OMDb pour récupérer les informations des films.
